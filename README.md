## 📂 Featured Projects

### 🖥️ RIZC-CCI - Custom ISA Emulator & Assembler
Project focused on low-level CPU emulation and instruction set design.
- designed a custom 16-bit instruction set architecture with a full fetch–decode–execute pipeline
- implemented a 16-register file, byte-addressable memory, and PC-relative branch handling in C
- built a companion Python assembler that resolves labels and compiles assembly into the emulator's machine code

  🔗 https://github.com/rpolishchuk3/RIZC-CCI-A-16-bit-Assembly-Interpreter-in-C

### ⚙️ Float From Scratch (Custom 32-bit Floating Point in C)
Project focused on low-level implementation of floating-point arithmetic.
- designed a custom 32-bit floating-point format with modified exponent/mantissa tradeoff
- implemented conversion, addition, and normalization using bitwise operations
- replicated core floating-point behavior without using built-in `float` or `double`

  🔗 https://github.com/rpolishchuk3/Float-From-Scratch
